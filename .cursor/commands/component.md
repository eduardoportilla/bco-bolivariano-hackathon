# /component

Create a new component with tests.

## Usage

`/component [ComponentName] [web|mobile]`

## Steps

1. Determine target (web or mobile)
2. Create component file with proper structure
3. Create test file with basic tests
4. Export from index.ts
5. Run `pnpm typecheck`

## Web Location

packages/ui-web/src/components/[Name].tsx

## Mobile Location

apps/mobile/src/components/ui/[Name].tsx
