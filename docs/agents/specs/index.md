## How to Use

1. Create a new spec file in `active/` with clear acceptance criteria
2. Follow the [FRAMEWORK](../FRAMEWORK.md) cycle: SPEC -> PLAN -> IMPLEMENT -> VALIDATE -> CLOSE
3. Once complete, move to `closed/` and log in [changes.md](./changes.md)

---

## Spec Template

```markdown
# [Feature Name]

## Objective
[What this feature does]

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Technical Notes
- Affected apps/packages
- Dependencies
- Constraints

## Related Guidelines
- `guidelines/[relevant].md`
```
